### 2.变量和类型

- 整型 (int) : Python 中可以处理任意大小的整数。
- 浮点型 (float) : Python 中处理浮点数类型的数据类型。
- 字符串型 (str) : Python 中可以用单引号和双引号括起来表示字符串类型。
- 布尔型 (bool) : bool类型 只有 `True` 和 `Flash` 两种值 。
- 复数型 (complex) : 和数学的表示一样，但是虚部由 `i` 改成了 `j`。

### 元组

元组与列表类似，但是使用()来表示，而且元组中的数据不能更改，但是长度可以动态改变，元组可以和列表互换

### 集合 (set)

概念参考数学中的集合，不允许有重复的元素，而且允许并集，交集，差集运算。
